## Problema 2: promoción en el menú de un restaurante

El menú se guarda en una matriz con el formato `[Nombre del producto, Categoría, Precio base]`. El programa aplica un 15 % de descuento a los productos de la categoría objetivo ("Plato fuerte") cuyo precio base sea mayor a $25.000. Los demás productos conservan su precio base.

La función `calcular_precio_final(categoria, precio_base)` hace el cálculo y `mostrar_informe(matriz)` recorre el menú e imprime el nombre, el precio base y el precio final de cada producto.

## Ejecución

```
python problema2_menu_restaurante.py
```

Requiere Python 3.6 o superior. No usa librerías externas.
